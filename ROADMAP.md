# Roadmap

## v0.4 — Hardening and community readiness

- Node.js 22/24 support and cross-platform CI.
- Symlink-safe project boundaries.
- MCP lifecycle validation and read-only defaults.
- Package installation smoke tests and metadata schemas.
- CodeQL, governance, support, and contribution policies.

## v0.5 — Real-world beta

- Incremental scanning and benchmarks.
- `.cmiignore` and documented ignore semantics.
- Monorepo and workspace awareness.
- More parser fixtures for Python, Go, Rust, and TypeScript aliases.
- Compatibility tests with multiple MCP clients.

## v1.0 criteria

- Stable storage migrations.
- Demonstrated use across multiple real repositories and operating systems.
- Reproducible npm publishing with provenance.
- Documented performance envelopes and parser accuracy limits.
- External user feedback incorporated into the public API.
