# CMI Licensing

Codex Memory Intelligence (CMI) uses a **source-available + separate commercial licensing** model for repository source after the 2026-08-11 licensing cutover.

## Current public-source license

Repository source after the cutover is offered under the **PolyForm Perimeter License 1.0.1**. See [`LICENSE`](LICENSE).

The public license allows use, modification, and distribution for permitted purposes, but it does not permit providing to others a product that competes with CMI as defined by the license.

CMI should therefore be described as **source-available**, not as OSI-approved open source.

## Legacy MIT releases

Public releases and tags that were already distributed under MIT remain available under the MIT terms that accompanied those versions. In particular, **v0.11.0 and earlier public releases are not retroactively relicensed** by this repository change.

Always check the `LICENSE` file contained in the exact tag, release, package version, or commit you are using.

## Commercial licensing

If your intended use is outside the permissions of the public license — including a product or service that may compete with CMI — contact the copyright holder to discuss a separate commercial license.

A separate commercial license is not automatically granted by this repository. Contact the project owner through the GitHub profile or repository before relying on commercial rights outside `LICENSE`.

## Project identity

Software-use rights and project identity are separate. See [`BRAND_POLICY.md`](BRAND_POLICY.md) and [`NOTICE`](NOTICE) for attribution, provenance, and official-project identity guidance.

## Contributions

Until CMI publishes a formal contributor licensing agreement, contributors should open an issue before submitting material code contributions. Field reports, bug reports, reproducible evidence, documentation suggestions, and design feedback are welcome.

Do not submit code or other material unless you have the right to contribute it.

## Legal note

This file explains the project's intended licensing structure; it does not replace the operative license terms in `LICENSE` and is not legal advice. Jurisdiction-specific questions should be reviewed by qualified counsel.
