# Support

Use GitHub Issues for reproducible bugs and focused feature requests. Include the CMI version, Node.js version, operating system, command used, expected behavior, and sanitized output.

Do not post credentials, private source code, customer information, or vulnerability details in public issues. Security reports must use GitHub's private security advisory flow described in [SECURITY.md](SECURITY.md).

This is a community-maintained project. Response times are best effort and no production support SLA is provided.
